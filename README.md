# Portfolio

Personal portfolio website showcasing my work, skills, and travels.

🔗 **Live:** [jantobiaswilhelm.github.io/Portfolio](https://jantobiaswilhelm.github.io/Portfolio/)

## About

I'm Jan, a Master's student at FHNW and Support Hero at twio.tech based in Basel, Switzerland. This site is a snapshot of what I do — code, photography, and exploring the world.

## Sections

- **About** — who I am, what I build with
- **Projects** — CX Lab Workspace, Lutem, NetflixRating, MovieNight, SQL Scrolls, Business Process Digitalization Guide
- **Experience** — what I'm doing right now, plus the whole CV as a scroll-driven timeline
- **Photography** — frames from my Fujifilm, with their EXIF
- **Contact**

The motion design (film-darkroom hero, rack-focus AF cursor, exposure timeline,
camera sounds) was prototyped in `prototypes/` first; `proto-6-mix.html` is the
approved direction.

## Tech Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- Lenis (smooth scroll) + a hand-rolled rAF motion loop, Web Audio for the camera sounds

## Run Locally

```bash
npm install
npm run dev
```
